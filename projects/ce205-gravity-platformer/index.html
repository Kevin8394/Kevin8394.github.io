CE 205: Gravity Platformer

An ARMv7 platformer for the DE1-SoC in which the player flips gravity, dodges arrows, and collects rabbits.

Context

Northwestern University2025
22animation frames
3platform surfaces
4arrow-key controls

Project overview

The project treats a small game as a complete low-level system: frame-by-frame animation, input buffering, collision and platform logic, random object generation, and a live score all run in ARM assembly.

01

Role

Implemented the game loop and integrated keyboard controls, player state, projectiles, collectibles, collision surfaces, and animation sequences.

02

Contribution

Used the board's keyboard FIFO and a pseudo-random generator while coordinating eight player frames, four arrow frames, and a ten-frame death animation.

03

Result

Delivered a playable hardware-targeted game with responsive gravity inversion and multiple interacting game systems.
